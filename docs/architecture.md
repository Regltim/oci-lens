# OCI Lens 架构与数据口径

OCI Lens 使用 React、TypeScript、Vite、React Router、Glasscn 与 ECharts 构建 Web 应用。Caddy 提供静态资源和同源 API 代理。服务端采用 Java 21、Spring Boot、Spring Security、SQLite 和 OCI Java SDK。部署使用单服务器、单管理员、单 OCI 采集范围。

## 页面与会话

顶部导航呈现概览、监控、用量与费用及设置。监控和用量使用页内切换。构建后的站点使用正常页面 URL，离线示例使用哈希路由。Caddy 对 SPA 路由回退到入口，API 路由直接交给服务端。

请求统一使用 `/api/v1`。管理员初始化从只读密码文件取得密码，SQLite 保存加盐哈希。登录使用服务端会话和 `OCI_LENS_SESSION` Cookie。写操作在发送前从 `/auth/csrf` 获取 CSRF 令牌。公开日报使用独立的限时 Bearer 令牌，由 `/r/{id}` 页面读取链接片段。

## 同步与覆盖

云端查询由管理员诊断、手动任务、历史补采及每日计划触发。本机账户可在没有 OCI 配置的情况下使用主机数据。OCI 主机启动时识别一次实例元数据，接入向导显示识别结果并组装 Cloud Shell 命令。

本机默认每 5 分钟采样。读取指定的宿主机文件系统容量与网卡计数，历史主机归档独立于当前采样保留周期。验证 OCI 连接后，计划每天 08:00 运行，时区默认为 `Asia/Shanghai`。资源 API 使用持久化的日请求计数和月点数预留，OCI SDK 请求重试关闭。监控请求按时间范围和资源维度预估点数。请求失败消耗本次预留，额度耗尽时任务进入暂停状态。

云端清单、实例指标、主网卡流量和费用按读取阶段发布，远程读取在数据库事务之外执行。重复流量采集按实例和 UTC 日期更新，小时桶按区间终点归到正确的 UTC 日。采样不足时显示缺口，已有有效行继续可查。费用用 OCI `computedAmount` 按币种保存，按 UTC 日查询。每日账单达到 48 小时的本地核对线才标为已覆盖，费用同步按近期窗口复核迟到账单。

历史补采按一个 UTC 日和一个来源执行。主网卡流量补采覆盖当前仍可查询的实例和网卡关联。历史账单查询与普通同步走同一用量预算。切换 OCI 范围时应用要求使用独立数据卷，原范围的数据保持原样。

云盘与用量使用独立的 SQLite 快照。云盘按当前区域和 Compartment 保存卷及挂载关系，包含未挂载卷。额度计算使用 Oracle SKU 对应的用量，A1 在主区域已确认时按主区域过滤，出站采用 OCI 计量单位。读取失败时，页面同时显示本轮状态和上次成功数据的时间。旧站流量按原窗口归档，原始云指标按时间范围查询，移出实时清单的实例仍可通过历史目录查询。

## 告警与费用

概览展示主机告警、实例新增或状态变化及月度预算提醒。手工费用和 OCI 费用分开记录，币种分别汇总。预算达到 80% 或 100% 时保留最新已达到的档位，出现应核对的账单缺口时暂停计算新档位。

维护窗口抑制该时间段的即时告警推送，本机采样和告警状态继续更新。微信通知和日报可选，接入时需提供自有配置。对外日报仅包含落库的脱敏快照。
