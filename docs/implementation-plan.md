# OCI Lens 实施方案

2026-11-19 · 已确认

## 导航与页面

参考 Apple Store 工具页和 Mac 机型比较页。桌面顶部把镜头标志、「概览」「监控」「用量与费用」「设置」排在同一个居中的导航胶囊内。手机端由顶部菜单提供同样的入口。实例详情、账单明细和同步记录支持直达。

| 入口 | 页面内容 |
| --- | --- |
| 概览 `/` | 上次同步、需要处理的事项、本轮变化、运行实例、昨日出站、本月已入账和本机磁盘。标题旁提供立即同步，状态区链接到同步记录。 |
| 监控 `/monitor` | 云实例、本机两个子页。列表展示实例状态、规格和历史指标，本机展示 CPU、内存、磁盘与运行时间。 |
| 用量与费用 `/usage` | 流量、费用两个子页。按实例和日期看流量，按月份和币种看费用，展示数据缺口、补采入口及月度预算。 |
| 设置 `/settings` | OCI 接入、同步计划、账号、通知。接入向导支持复制完整的 Cloud Shell 只读授权命令、检查连接和查看错误指引。 |

## 视觉

顶部导航、页内标签、指标、同步状态和业务面板使用 Liquid Glass。图表、表格和命令区使用透光较少的厚玻璃，保持内容对比度。浅色主按钮和选中状态采用浅冰蓝底与深蓝文字。文字优先使用系统 SF Pro 和苹方。动效集中在菜单展开和按钮按压。

概览以双栏组织指标和趋势、同步与告警，小屏按阅读顺序纵向排列。登录页和工作区各有一组深浅背景，登录页使用光学镜头，工作区使用玻璃曲面。登录前后都可以切换主题，选择保存在当前浏览器。工作区导航提供退出登录。按钮按主操作、次操作、文字操作和危险操作区分，选中和禁用状态随主题变化。支持光学折射的浏览器使用边缘位移，其他浏览器保留透明、模糊与高光材质。界面遵循系统的降低透明度设置。

图表区间使用支持方向键的分段单选按钮。实例搜索和状态筛选共用标签基线与控件高度。设置根据真实连接状态显示对应指南和操作，保存、撤销、检查和维护窗口结束都提供明确反馈。

参考 [Apple 官网](https://www.apple.com.cn/)、[Mac 机型比较](https://www.apple.com.cn/mac/compare/) 和 [Apple.com DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md)。

## 实施顺序

1. 从现有 React、Glasscn、ECharts 组件提取正式 Web 应用。实现顶部导航、独立页面、当前选中态和移动菜单。制作可离线打开的组件原型及桌面、手机截图。
2. 采用单节点 Docker Compose、Spring Boot 和 SQLite。首次登录即可查看本机。在「设置 → 账号」验证当前密码后，可单独修改账号名或密码，也可一并修改。OCI 主机预填实例、租户和 Compartment 后生成一条 Cloud Shell 命令。其他主机按 API Key 向导接入。账单权限按需开启。
3. 本机默认每 5 分钟采样。OCI 接入成功后默认按展示时区每天 08:00 同步。页面及筛选只查询本地数据。手动、定时、补采与重试共用请求和检索点数预算。超过上限暂停并保留上次成功数据。
4. 优先交付变化摘要和采集覆盖提示，随后交付预算、维护窗口和可选微信通知。交付 Compose、接入教程和架构口径更新。

## 验收

- 桌面和 390px 窄屏验证顶部导航、键盘、深链接和返回行为，检查 Chromium 和 Safari。
- 使用空数据卷启动后可登录并查看本机状态。真实 OCI 租户验收一键授权、连接诊断和首次同步。
- 页面打开、切换标签和筛选均无 OCI 调用。失败或达限时保留快照，区分过期数据、待出账及真实零值。
- 容器重启后保留配置、快照和同步记录。发行提供 Compose 文件、接入教程和可离线打开的原型。
