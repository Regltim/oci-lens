# 本机监控、历史迁移与 OCI 额度

## 第一期

- A1 本机入口默认打开本机监控，可在设置中选择云实例。概览优先展示本机 CPU、内存、磁盘和网卡。本机与 OCI 实例通过自动识别的实例 ID 关联。
- A2 按指定的宿主机只读挂载路径采集文件系统容量，展示总容量、已用、可用和使用率。发布前对照 Linux `df`，验证附加挂载和采集失败状态。
- A3 给云指标提供日期筛选与历史实例入口。流量和费用提供可查月份。升级迁移工具的只读对账，保留旧流量与旧主机采样的来源，沿用备份、事务和去重。以旧新库抽样、重复导入及同步后历史可查作为验收条件。

## 第二期

- A4 通过 OCI 只读云盘清单采集启动卷、块卷和挂载关系。云实例详情显示同步状态、最后成功时间和容量，失败保留旧快照。
- A5 概览与用量页展示 A1 计算、块存储和出站额度。预设来自 Oracle Free Tier，按租户允许调整。按已核对的 OCI 计量项计算月度用量，缺数据时标记状态；附带统计范围和更新时间。通过真实租户控制台验证卷列表、A1 用量和出站计量，覆盖账单关闭、权限不足和数据迟到。

使用可重跑的增量数据库结构。正式迁移由管理员基于实际数据库执行，使用现有迁移备份作为恢复点。OCI 同步继续通过既有应用请求预算约束远端查询。
