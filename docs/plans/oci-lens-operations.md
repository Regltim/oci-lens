# OCI Lens 单机运维脚本

- A1 提供统一 Bash 入口，支持初始化、启动、重建、停止、状态、日志与诊断。沿用 Compose 项目、配置和数据卷。重建先完成镜像构建，再对既有 SQLite 做一致性备份，最后等待后台和 Web 健康。
- A2 支持一致性备份和旧站迁移。按 Compose 配置和已存在的容器定位实际数据库。迁移默认只读预检，显式应用前停止新站后端，使用现有事务导入流程，结束后恢复此前运行状态。
- A3 重复初始化和重建保留当前管理员账号、密码与已有初始化文件。数据库已有账号而初始化文件缺失时，仅恢复 Compose 所需的空挂载文件。
- A4 本机运维员可以显式执行 `reset-password`。采用终端隐藏输入或 `--generate` 生成随机密码，复用现有密码哈希和管理员更新机制。停止此前运行的后端，备份 SQLite 后更新已存在的账号，恢复服务并等待健康。生成凭据以受保护的文件交付。
- A5 验证新安装、重建保留已改密码、缺失初始化文件的存量恢复、备份和迁移失败恢复、显式重置的账号及会话状态。以已有数据卷备份作为升级或重置的恢复点。
