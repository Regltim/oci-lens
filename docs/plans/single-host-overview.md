# 单机概览与统一历史

- 将同机导入记录并入本机和网卡的常规历史查询。直接读取既有 SQLite 数据，重复日期或时间点采用新站采集值。保留旧数据的备份与去重行为。
- 概览以 CPU、内存、根分区、网卡入站和出站的采样趋势为主。百分比和速率使用各自的坐标轴，去掉瞬时值卡片与实例清单。本机页提供常规日期查询。
- 将免费额度的界面改为本月使用概况。单机主网卡按 UTC 月汇总，注明日期覆盖。OCI 出站计量独立显示，单机流量以实际采样值呈现。
- 云盘读取失败显示阶段和状态码，引导检查现有 OCI 授权或目标范围。原有快照继续可见。
- 验证存量 SQLite 记录合并、重复数据、样本缺失和零值、月度网卡数据、权限失败、页面入口。真实 OCI 和部署机数据由管理员验收。
