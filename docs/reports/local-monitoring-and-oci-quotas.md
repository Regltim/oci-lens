## 浏览器走查

用户选择执行浏览器验证。使用 ego-browser 对 Vite 示例环境完成桌面与 390 px 窄屏走查。

- 桌面验证了本机默认入口和偏好切换、主机硬件和文件系统数据、网卡趋势、关联云实例与云盘、日期筛选、额度缺失状态及设置保存后回显。
- 费用页的月份选择器在走查中发现漏接，已接入有记录月份下拉框。复测验证了日期输入、从无账单月份切回有记录月份，以及账单重新渲染。
- 390 px 下验证了导航、本机、云实例详情、历史实例、旧站流量、费用月份、额度明细和额度设置，各页面无整体横向溢出。
- 历史实例、旧站流量和历史主机在示例环境覆盖了入口及空状态。归档记录的导入与查询由 SQLite 样本和 Java 测试验证。

## 部署验收

- Linux 主机上将本机根分区与附加挂载点的容量对照 `df`，核对接口选择和网卡趋势。
- 用实际部署中的旧站与新站 SQLite 文件预检，对照日期和待导入数量。正式导入需暂停新站后端，使用脚本生成的目标库备份作为回滚点。完成后抽查历史实例、费用、旧站流量和历史主机采样。
- 在真实 OCI 租户核对云卷及挂载关系、主区域和用量 SKU，检查账单读取关闭、报表数据延迟和权限不足的展示。租户范围未完整可见时，存储只显示已采集范围内的容量。
