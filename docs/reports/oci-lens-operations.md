# OCI Lens 运维脚本验证

实施范围见[运维脚本方案](../plans/oci-lens-operations.md)。

| 验证 | 结果 |
| --- | --- |
| Java 21 Maven 套件 | 91 项通过。微信客户端的 7 项本机回环 Mock 测试单独执行 |
| 账号回归 | 在临时 SQLite 中验证网页改密和改名后重新初始化仍可登录。离线命令保留管理员 ID 和账号名，旧密码和旧会话失效，校验失败时原凭据保留 |
| 运维脚本 | 使用模拟 Docker 和实际临时 SQLite 库走过初始化、启动、重建、停止、状态、诊断、日志、备份、迁移和密码重置。验证构建失败时原服务继续运行，迁移或重置失败后恢复原本运行的后端 |
| SQLite 备份 | 验证运行中的 WAL、关闭后没有 WAL 辅助文件的只读目录，以及带有待恢复 WAL 的停机副本。备份能恢复已提交记录，源文件内容保留 |
| 配置及语法 | Bash 语法、Compose 配置和实际 Compose JSON 中的挂载解析均通过 |

本机 Docker 引擎未运行，完整容器重建和真实 OCI 主机上的运维操作待部署验收。部署验证应在独立测试卷上覆盖首次启动、改密后重建、离线重置及旧库预检。
